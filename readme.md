# 🌧️ Rain for Relax

A minimalist, single-page ambient app that plays soothing rain sounds over a beautiful looping video. Perfect for relaxation, focus, or sleep.

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Website](https://img.shields.io/website?url=https%3A%2F%2Frain-for-relax.yuricunha.com)](https://rain-for-relax.yuricunha.com)

## 🌟 Features

- 🎥 Beautiful looping rain video background
- 🌊 High-quality rain audio that loops seamlessly
- 🎚️ Volume control with keyboard shortcuts
- 🌙 Clean, distraction-free interface
- 📱 Fully responsive design
- ⚡ Lightning fast (no frameworks, no build step)
- 🔒 Privacy-focused (runs entirely in your browser)

## 🚀 Quick Start

1. Visit [rain-for-relax.yuricunha.com](https://rain-for-relax.yuricunha.com)
2. Click "click here to begin" to start the audio
3. Use the volume controls to adjust the sound
4. Press `M` to mute/unmute, or use the volume slider

## ⌨️ Keyboard Shortcuts

- `M` - Toggle mute
- `Space` or `Enter` - Toggle mute
- `↑` - Increase volume
- `↓` - Decrease volume
